# Сессионный проект «Безопасность GNU/Linux»

**НИЯУ МИФИ, 2026** · Студент: **373175**

Настройка базовых средств защиты сертифицированной ОС **РЕД ОС 8** (сертификат ФСТЭК России № 4060) без графического интерфейса и развёртывание веб-сервера для публикации результатов ГИС.

## Окружение

| Параметр | Значение |
|---|---|
| ОС | РЕД ОС 8, ядро 6.12 (aarch64) |
| Виртуализация | UTM на macOS, сеть в режиме моста |
| Имя хоста | `mephi-2026.domain.local` |
| Интерфейс управления | только командная строка |

## Проверка работы

- **Права доступа (5.1)** проверены на практике: все три разработчика дописывают в один файл; куратор читает, но запись отклоняется; посторонний пользователь не может открыть каталог.
- **Длина пароля (6.2)**: `pwscore` отклоняет 8-символьный пароль с сообщением о минимальной длине 12.
- **Вход (6.1)**: `su - curator1` → `This account is currently not available`; `su - user1` — вход выполнен.
- **Сохранение после перезагрузки**: все артефакты сняты после `reboot` — монтирование, автозапуск nginx и межсетевого экрана, режим SELinux, привилегии, ACL и сроки паролей сохранились.

## Дополнительные меры защиты

Сверх требований задания включён межсетевой экран `firewalld` с автозапуском. Разрешены только необходимые сервисы — `ssh` и `http`; служба `mdns`, открытая по умолчанию, закрыта. Доступность сайта из локальной сети проверена с хоста. Конфигурация — в `firewall.out`.

## Примечания

**Пинг.** В режиме «Общая сеть» UTM протокол ICMP блокировался VPN хост-системы: хост также не пинговал 8.8.8.8, при этом TCP работал. Сеть ВМ переведена в режим моста, после чего пинг проходит; адрес по-прежнему выдаётся по DHCP.

**tcpdump.** В РЕД ОС 8 пакет поставляется без бита set-UID и без привилегий (`-rwxr-xr-x`), поэтому обычный пользователь запустить его не мог. Вместо полных прав root выданы только две привилегии — по принципу наименьших привилегий. В реальной системе их следовало бы ограничить группой администраторов сети.

**Вход кураторов.** Выбран `nologin`: запрет интерактивного входа виден в `passwd`. Более узкая реализация формулировки «локально» — модуль `pam_access` со строкой `-:curators:LOCAL` в `/etc/security/access.conf`: он запретил бы вход с консоли, сохранив сетевой.

**Сроки паролей.** Умолчание в `login.defs` действует только на новые учётные записи, поэтому для существующих срок применён отдельно через `chage`.

**`/etc/shadow` и `history.out`.** Опубликованы по требованию задания. Хеши и учебные пароли относятся к изолированной учебной ВМ и нигде не переиспользуются. Пароль, переданный через `chpasswd`, виден в истории, поэтому пароли разработчиков затем изменены интерактивно. Строки «команда не найдена» в истории — случайная вставка вывода терминала, история не редактировалась.
